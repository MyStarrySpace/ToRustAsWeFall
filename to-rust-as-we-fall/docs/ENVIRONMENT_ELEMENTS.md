# Environment Elements Register — per-act environmental puzzle elements

**Owner: the director** (edit freely — this document is yours). Generated 2026-07-02 by the
per-region design fan-out with adversarial canon vetting (2 kept clean, 50 amended by their
skeptics, 1 killed — the kill is logged in the appendix). Working names are DESCRIPTIVE, never
new world-nouns; naming anything properly is the director's call. Act 3 regions are flagged
PROPOSAL — the GDD itself (L505/L729) says they need this design pass; nothing there is canon
until approved.

**How to read an entry:** one element = one mechanism = ONE verb. TELL is its pause-readable
telegraph (everything that hurts telegraphs). SHADOW is the Aster+Peris-only solve in the same
geometry. METRIC names which tension metric it serves (1 clever-solve / 2 positioning / 3
just-enough-stamina at the 40wu bar). BUILDABILITY is honest: COMPOSABLE-NOW lists only systems
that exist; NEEDS-BUILD names exactly one new class for the ledger.

Companion register: ECOLOGY_COMBOS.md (flora x fauna combinations; its combo cards compose with
these elements).


## Act 1 — Institutional breakdown (Zone 2 early, Shelters 1-10)

### Plumbing Power Project

#### 1. Valve-rotation terminal (re-aim the pipe run)

- **WHAT IT IS:** A rotary maintenance valve on a pump-run junction that re-aims which of two adjacent channel runs carries the wash. The Plumbing Power Project is a succeeded-but-captured district: its category is defined at GDD L727 ('succeeded-but-captured projects have working infrastructure with abandoned practice') and the district is water infrastructure (GDD L713) whose project category is one of the three the GDD assigns per name (GDD L708). So the drainage still works but the tending practice lapsed (the ependymal plumbing expertise embodied by Pendy, GDD L2934, is exactly the abandoned practice) — the valves sit mid-fault, most runs constricted and one open. That 'one open amid constricted' silhouette is the same visual grammar as the mid-Act-2 Outflow Expander's dilated channel amid constricted ones (GDD L2088-2094, cited as imagery precedent, not as this location). The valve mechanic itself — turning a valve opens one lane and floods another, and turning one changes which next valve you can reach, so clearing a path is a sequence-ordering logic puzzle — is the Act-2/Zone-3 Acid Core landmark puzzle's mechanic (GDD §10.4.6, L2116-2122), borrowed as a mechanical vocabulary and re-themed to Act 1; this element must NOT duplicate or pre-empt that named cure-component set-piece. The wash is iron backwash, the body's glymphatic clearance failing, not water (GDD L2070; CHANNELS_DESIGN #7 L150-154).
- **VERB:** rotate
- **TELL:** A rotated valve has a committed wind-up; the flow-strip of the run it is about to charge brightens along its whole length before the backwash arrives, so the lane going lethal is readable during the rotation (the existing channels flow-strip telegraph, CHANNELS_DESIGN L128/L184). Any co-located patrol carries the standard enemy detection telegraph.
- **ARCHETYPES:** 6 pattern-reconstruction (track channel states, reason the turn sequence); 8 class-gated (Endo's handed safe-diagonal vs the pair's derived ordering); 5 split (rotating reconfigures reachability, naturally splitting the party — the same reconfiguration-splits-the-party behavior as the Acid Core, GDD L2118).
- **PERCEPTION_LOCK:** The map of which valve feeds which run is legible only by composing WHERE (Peris BLOOM lights flooded-vs-dry lanes and fertile lip cells) with WHEN (Aster TRACE names the backwash onset per run plus the correct turn order); Endo's survival read hands the safe dry diagonal outright. Neither register alone yields the ordering.
- **SHADOW (Aster+Peris):** No Endo, so no handed safe-tiles. Aster TRACE derives the turn sequence and times each run's dry gap; Peris BLOOM plants anchor-flora on a fertile junction lip to raise a causeway across the ONE lane the valve topology can never open (a lane no rotation sequence clears — the reason a causeway is required and not redundant with the valves). Harder: a correct multi-step ordering plus a germination wait under the patrol. Same junction geometry as the presented solve, never easier. (The BLOOM causeway reuses the Holdfast Crossing design target, CHANNELS_DESIGN L199-202.)
- **METRIC:** (1) optimal-solution feel (DESIGN_PRINCIPLES tension metric 1) — the ordered valve sequence is a plan you feel clever for finding, not a walk.
- **BUILDABILITY: NEEDS-BUILD** — One new object class: a flow-router valve (a Terminal variant whose interact reassigns which Channel flood-strip is active between two runs, tracking per-valve state). Composes existing Channel flood strips, Terminal dwell, analytic scheduler cadence, and the multi-level grid; the re-aim/state-swap controller is the one new piece. Dependency to confirm: the shadow's BLOOM causeway (cells excluded from the wash) is a documented Holdfast design target and may not be shipped yet — if unbuilt it is a shared build with the Holdfast crossing, not a second new class for this element.
- **CANON:** GDD L708 (name-carries-category), L713 (Plumbing = water infrastructure), L727 (succeeded-but-captured DEFINITION: working infrastructure, abandoned practice); L2070 (glymphatic/AQP4 basis); L2934 (Pendy, ependymal plumbing expert — the lapsed tending practice); L2088-2094 (Outflow Expander dilated-amid-constricted IMAGERY precedent, mid-Act-2 landmark); L2116-2122 (Acid Core §10.4.6 valve-routing sequence-logic MECHANIC borrowed and re-themed; L2118 reconfiguration-splits-party); CHANNELS_DESIGN #7 L150-154 (iron backwash not water), L128/L184 (flow-strip tell), L199-202 (Holdfast shadow causeway precedent); DESIGN_PRINCIPLES tension metric 1 (optimal-solution feel).

#### 2. Flow-strip beat-reader station

- **WHAT IT IS:** A wall-mounted maintenance readout wired to a downstream flow-strip that CONTINUOUSLY posts the next surge onset of a crossing wash whose own strip is rusted-over or submerged on this run. Its readout is passively visible from the crossing approach (no interaction needed to SEE the warning); an optional dwell only deepens the read to one section ahead, the same one-section lookahead Aster TRACE gives from open water. It is a shared, hands-free WHEN-read for the whole party, where TRACE is Aster-only and momentary. Diegetically it is an untended maintenance fixture left running in a district that still functions but is no longer tended, consistent with the class-coded, water-infrastructure register of the Plumbing Power Project; it is NOT asserted as a specific ependymal/Pendy installation (Pendy is DLC-exclusive and base-game ependymal presence is a log in The Open Files, not here).
- **VERB:** read-the-beat
- **TELL:** The station's readout is ALWAYS ON and co-visible from the crossing approach: it pulses on the true scheduler cadence and brightens a beat before each surge, so it REPLACES the rusted/submerged strip as the section's implicit telegraph, present from first sight and never gated behind an interaction or a failure (CHANNELS_DESIGN #3, template 'anything that can wash you MUST telegraph first'). The crossing wash's own strip being dark is the FICTION for why the readout matters, not a removal of the telegraph. Aster TRACE remains a second, momentary WHEN-read.
- **ARCHETYPES:** 7 stealth-and-time (the read gates a timed crossing); 8 class-gated (the station or Aster TRACE is the WHEN provider the pair must supply, and Peris BLOOM is the WHERE provider in every solve).
- **PERCEPTION_LOCK:** The onset is hidden from a plain look at the crossing (its own strip is dark). WHEN comes from the always-on station readout OR Aster TRACE; WHERE (which parallel lane is walkable in the dark stretch) comes ONLY from Peris BLOOM. Both registers are required in BOTH solves (Peris always supplies WHERE); reading one without the other still gets you swept.
- **SHADOW (Aster+Peris):** Skip or lose the station and Aster TRACE substitutes the WHEN, but it must be re-read in-section, is momentary, and serves only Aster's own timing (not persistent, not shared); Peris BLOOM lights the dark lane in both solves so the pair dash on Aster's called window. Same geometry, same hazard, harder because the WHEN-read is neither persistent nor shared. Endo is not required.
- **METRIC:** (1) clever optimal solve, timing a blind crossing by composing an always-on WHEN read (station, or an earned momentary Aster TRACE) with Peris BLOOM's WHERE.
- **BUILDABILITY: COMPOSABLE-NOW** — Composes a Channel flood-strip with analytic next-onset (next_onset_in), a passive worldspace/HUD readout that surfaces that already-computed onset, and the existing TRACE cadence read. No new object class; the station is a data/UI binding of a remote channel's onset. The persistent SHARED readout is slightly beyond TRACE's momentary note, but it is a label update, not a new class.
- **CANON:** GDD L708 (class-coded institutional/maintenance register) + L713 (district name Plumbing Power Project = water infrastructure); L2934 (Pendy/ependymal = the plumbing/fluid role, general) with L2870/L2932 noting Pendy is DLC-exclusive and base-game ependymal presence is a log in The Open Files, so the readout is framed as a generic untended maintenance fixture, NOT an asserted ependymal installation; CHANNELS_DESIGN Section-design #2 (two registers WHERE+WHEN composed) and #3 (the implicit tell is ALWAYS present from first sight, never gated, so the station readout IS that always-on tell) plus the Holdfast worked example; test --test-wash-relay-trace-cadence (TRACE reads the current section's real 4.0s beat AND one section ahead from open water, flush=0).

#### 3. Sloperope re-anchor point

- **WHAT IT IS:** An inclined pump-shaft wall where Climbvine (worker-name Sloperope) grows, serving as the chunk's connect-back: a member swept out by a wash is carried down to the start shelter but stays MOBILE, and climbs this pre-grown vine to rejoin the ascent at the chunk instead of redoing the stretch (CHANNELS_DESIGN Failure & recovery; DESIGN_PRINCIPLES P11). Canon places Climbvine's first appearance in the Plumbing Power Project on a side passage, taught by geometry, not a prompt (GDD L1487). Recovery is a CHOSEN TIME investment, not a freebie: the Sloperope is the slow, free/cheap climb (the Terminal is the fast, ATP/time-priced counterpart), and the climb duration scales with how deep the member fell (CHANNELS_DESIGN Section-design #6; DESIGN_PRINCIPLES P11). Climbing is slow and exposes the climber on the wall, where wall-dwelling terrain hazards deny wall-hugging routes and shape the ascent — but the pitch is always beatable and never soft-locks.
- **VERB:** climb
- **TELL:** The wall hazard telegraphs before it bites — Crust pores dilate and puff before venting acid, or a Spiker branch brightens along its firing line (fauna_roster L27, L31) — so the climber has a readable window to time each pitch.
- **ARCHETYPES:** 2 plant-as-tool (in the shadow, Peris grows the traversal herself); plus the connect-back recovery archetype (the chunk's re-anchor device that lets a swept-but-mobile member self-climb back to the current chunk — NOT a carry of a downed body).
- **PERCEPTION_LOCK:** Whether a re-anchor even exists on a wall is a WHERE read (Peris BLOOM: Climbvine only grows on slopes, so plantable/grown surfaces are hers to see); WHEN the wall-hazard vents is Aster TRACE; Endo's survival read marks the safest pitch outright (a convenience, never required).
- **SHADOW (Aster+Peris):** No pre-grown rope on the SAME slope: Peris BLOOM must plant and tend a Climbvine there herself (player-planted, slope-only, bounded by growth time and 2-vine hand slots) to build the re-anchor, while Aster TRACE times the climb between vents. Harder: a germination/harvest wait plus a hazard-timed ascent, no handed safe pitch. Aster+Peris only; Endo not needed.
- **METRIC:** (2) positioning significance + depth-scaled TIME cost — recovery prices the fall depth in climb DURATION, not stamina (Sloperope is the slow free/cheap option; Terminal is the priced one). A deep wash costs a long, exposed climb, so pushing on while a member is down is a real time investment the party may defer; all-three-washed means redo the chunk.
- **BUILDABILITY: NEEDS-BUILD** — One new object class: a Climbvine/Sloperope anchor flora that registers a grid inter-level link (add_inter_level_link exists; per P14 L240 'no flora object places links' yet, and no Climbvine object is shipped — only flure.gd/capbage.gd/flora_light.gd). The multi-level grid and ladder/ramp traversal exist; the flora-places-a-link binding plus the Climbvine planting/growth/hand-slot bounds are what this class must add.
- **CANON:** GDD L1483-1485 (Climbvine roster + dual register Climbvine/Sloperope), L1487 (Plumbing Power Project first appearance, side passage, taught by geometry), L1489 (harvest bounds: one vine/rest cycle, 2 hand slots, slope-only); fauna_roster L27 (Crusts, pores dilate/puff tell), L31 (Spikers, branch-brightens tell); CHANNELS_DESIGN Failure & recovery (L75-91) + Section-design #6 (L145-148, 'Sloperope = slow free climb'); DESIGN_PRINCIPLES P11 (L181, L314, depth-scaled TIME recovery), P14 (L240, add_inter_level_link substrate exists / no flora object places links).
